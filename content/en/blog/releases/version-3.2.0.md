# RsyncUI 3.2.0 — Translation test release

<div class="alert alert-secondary" role="alert">

This test release introduces a Simplified Chinese translation of RsyncUI. It is intended for reviewing the translation, and further updates may follow based on feedback.

</div>

## 🌐 Simplified Chinese translation

- Added a Simplified Chinese translation of the application interface.
- This release is available for translation review. Please report any wording, terminology, or layout issues you find.
- The translation may be revised in subsequent updates as feedback is received.
